## 2. Sanity check po apply

W Supabase SQL Editor:

```sql
-- Views są security_invoker?
select table_name, table_schema, options
  from information_schema.views_options
 where table_name in ('automations_dashboard','clients_dashboard');
-- alt:
select c.relname, c.reloptions
  from pg_class c join pg_namespace n on n.oid=c.relnamespace
 where n.nspname='public' and c.relkind='v'
   and c.relname in ('automations_dashboard','clients_dashboard');

-- api_keys.created_by jest TEXT?
select column_name, data_type from information_schema.columns
 where table_schema='public' and table_name='api_keys' and column_name='created_by';
-- → text

-- Bucket reports istnieje?
select id, name, public from storage.buckets where id='reports';
-- → reports, false

-- Backfill — żaden wiersz nie ma user_id null?
select 'automations' t, count(*) miss from automations where user_id is null
union all select 'clients', count(*) from clients where user_id is null
union all select 'reports', count(*) from reports where user_id is null
union all select 'executions_raw', count(*) from executions_raw where user_id is null;
-- → wszędzie 0
```
